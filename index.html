The fly car system

You call 911.
We're already
moving.

Your local ambulance responds, and so does a Greene County Paramedic in a rapid-response SUV. The truck carries every medication and intervention New York State allows a paramedic to provide, plus the monitors, infusion pumps and ventilators you would normally only see on a critical-care transport unit.

Every call we run is a 911 call. We don't do inter-facility transfers. The model was built for a county of mountains and long roads, and we have been refining it since August 1, 2000.

What the state found

The model New York now recommends

In March 2026 the New York State Rural Ambulance Services Task Force delivered its report to the Legislature. It describes rural EMS as "teetering on the brink of collapse" and makes 38 proposals. Number 8 is tiered response: a local ambulance plus a paramedic fly car, with the closest appropriate unit sent to every call.

Greene County has run that system since August 2000. Today it is six paramedic units covering thirteen towns.

Read the task force report

"Tiered response models consisting of BLS transporting units and ALS non transporting EMS vehicles may greatly increase response capabilities and create more resilient response systems by preserving ALS level care for when it is needed."
